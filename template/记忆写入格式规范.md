# 记忆写入格式规范

## 核心原则

1. **能更新就不新建** — 写入前搜索查重
2. **source 必须填写** — `workbuddy` / `claude` / `codex`
3. **复用已有标签** — 全小写英文
4. **正文第一段写摘要**
5. **区分事实与推断** — 用户明说的标 `confidence=high`；自己推断的标 `medium`/`low` 且 `verified=false`

## 标签规范

- 全小写英文
- 常见标签: `python`, `android`, `docker`, `security`, `fix`, `project`, `tool`, `tutorial`, `network`, `deploy`

## 语义字段

| 字段 | 取值 | 用途 |
|------|------|------|
| `type` | fact / preference / decision / experience / episodic / project / constraint / workflow / temporary | 记忆类型 |
| `confidence` | high / medium / low | 可信度 |
| `verified` | true / false | 是否经用户确认（置 true 自动记录 `verified_at`） |
| `scope` | global / project / temporary | 生效范围 |
| `project` | 项目标识 | `scope=project` 时必填 |
| `status` | candidate / active / stale / deprecated / archived | 生命周期；检索默认隐藏 archived |
| `supersedes` | 标题 | 本条取代了哪条旧记忆 |
| `conflicts` | 标题列表 | 与之矛盾的条目 |

> 完整说明见 `rules/记忆写入格式规范.md`。

## 什么时候写

| 场景 | 动作 |
|------|------|
| 技术决策 | 更新项目页 |
| 修了 bug | 写修复记录 |
| 主人说"记住" | 写一条新记忆 |
| 日常闲聊 | 不用写 |
