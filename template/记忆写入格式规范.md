# 记忆写入格式规范

## 核心原则

1. **能更新就不新建** — 写入前搜索查重
2. **source 必须填写** — `workbuddy` / `claude` / `codex`
3. **复用已有标签** — 全小写英文
4. **正文第一段写摘要**

## 标签规范

- 全小写英文
- 常见标签: `python`, `android`, `docker`, `security`, `fix`, `project`, `tool`, `tutorial`, `network`, `deploy`

## 什么时候写

| 场景 | 动作 |
|------|------|
| 技术决策 | 更新项目页 |
| 修了 bug | 写修复记录 |
| 主人说"记住" | 写一条新记忆 |
| 日常闲聊 | 不用写 |
